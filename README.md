# 📚 API Simples – Aula de Back-End

Este repositório foi criado com o objetivo de acompanhar o desenvolvimento de uma API simples durante as aulas de Back-End do Curso Técnico de Desenvolvimento de Sistemas.

A proposta é aplicar, na prática, conceitos fundamentais de construção de APIs, organização de código e comunicação entre cliente e servidor.

---

## 🚀 Objetivo:

**`Desenvolver uma API básica para:`**

* Compreender o funcionamento de requisições HTTP;
* Estruturar um projeto back-end;
* Testar a API com ferramentas apropriadas;

---

## 🛠️ Tecnologias Utilizadas

* Linguagem: JavaScript;
* Framework: Node.js;
* Ferramentas de teste: Vercel.

---

## 📖 Aprendizados

**`Durante o desenvolvimento deste projeto, foram abordados conceitos como:`**

* Estrutura de uma API Simples;
* Métodos HTTP;
* Organização em camadas;
* Boas práticas de desenvolvimento back-end;
